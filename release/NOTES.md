# FLAMORIS Generation Controller v1.0.2

Adds internal-service-only discovery of recent completed external generations for an exact verified issuer/subject. Studio can automatically register its linked client's completed results without scanning media directories or downloading files. The bounded private discovery index survives restart; older jobs retain explicit import/retrieval.

The external MCP catalog remains at 25 tools. Authentication, single Controller ownership, unknown/no-replay reservations, job/asset identities and configured human output directories are preserved. No database migration, provider activation, model download or media move is required.

Generation MCP embeds this pinned library and publishes the runnable release. Hub individual credentials, signed provenance and Studio account bindings must be configured by the operator; publishing the library does not provision credentials or change hosts.
